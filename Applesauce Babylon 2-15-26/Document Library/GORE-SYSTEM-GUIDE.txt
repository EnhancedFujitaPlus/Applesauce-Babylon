GORE SYSTEM USAGE GUIDE
========================

The gore system is now modular and works with Three.js r182!

## FILE STRUCTURE:

your-game-folder/
├── applesauce-core-r182-with-gore.js   ← Updated core with gore
├── applesauce-gore-r182.js             ← Gore module
├── three.module.js                     ← Three.js r182
└── (your other files)

## HOW IT WORKS:

The gore system is automatically loaded when you create the game engine with `goreEnabled: true`:

```javascript
const game = new ApplesauceCore({
    goreEnabled: true  // Gore system will be initialized
});
```

If you set `goreEnabled: false` or omit it, gore will be disabled (default is enabled).

## GORE METHODS:

Once enabled, you can access gore through `gameInstance.modules.gore`:

### 1. Basic Blood Splatter
```javascript
// Create blood splatter at a position
const position = new THREE.Vector3(x, y, z);
const velocity = new THREE.Vector3(vx, vy, vz);

gameInstance.modules.gore.createBloodSplatter(position, velocity, 30);
// Parameters:
// - position: Vector3 where blood appears
// - velocity: Vector3 direction blood sprays
// - amount: number of particles (default 30)
```

### 2. Blood Pool (Ground Stain)
```javascript
// Create a blood pool on the ground
gameInstance.modules.gore.createBloodPool(position, 2);
// Parameters:
// - position: Vector3 where pool appears
// - size: radius of pool (default 2)
```

### 3. Body Parts (Gibs)
```javascript
// Create flying body parts
gameInstance.modules.gore.createGibs(position, velocity, 5);
// Parameters:
// - position: Vector3 where gibs spawn
// - velocity: Vector3 direction gibs fly
// - count: number of gibs (default 5)

// Creates random body parts: heads, limbs, torsos
// They tumble through the air with physics!
```

### 4. Massive Splatter (Extreme Gore)
```javascript
// For dramatic deaths - combines all effects!
gameInstance.modules.gore.createMassiveSplatter(position, velocity);
// Creates:
// - 50 blood particles
// - Large blood pool
// - 8 body parts
// Perfect for high-speed collisions!
```

### 5. Clear All Gore
```javascript
// Remove all blood and gibs from the scene
gameInstance.modules.gore.clear();
```

## EXAMPLE SCENARIOS:

### Scenario 1: Player Crashes Into Wall
```javascript
// In your collision detection code:
if (playerHitWall) {
    const playerPos = player.position.clone();
    const impactVelocity = player.velocity.clone();
    
    // Scale gore based on speed
    if (speed > 1.0) {
        gameInstance.modules.gore.createMassiveSplatter(playerPos, impactVelocity);
    } else {
        gameInstance.modules.gore.createBloodSplatter(playerPos, impactVelocity, 20);
        gameInstance.modules.gore.createBloodPool(playerPos, 1.5);
    }
}
```

### Scenario 2: Enemy Dies
```javascript
// When an enemy is destroyed:
function killEnemy(enemy) {
    if (gameInstance.modules.gore) {
        const pos = enemy.position.clone();
        const vel = new THREE.Vector3(0, 0.2, 0); // Upward spray
        
        gameInstance.modules.gore.createBloodSplatter(pos, vel, 40);
        gameInstance.modules.gore.createGibs(pos, vel, 6);
        gameInstance.modules.gore.createBloodPool(pos, 2);
    }
    
    scene.remove(enemy);
}
```

### Scenario 3: Continuous Damage (Lava, Spikes)
```javascript
// For damage over time:
let lastGoreTime = 0;

function updateDamageZone(player) {
    const now = Date.now();
    
    // Trigger gore every 500ms while in damage zone
    if (now - lastGoreTime > 500) {
        if (gameInstance.modules.gore) {
            const pos = player.position.clone();
            const randomVel = new THREE.Vector3(
                Math.random() - 0.5,
                0.3,
                Math.random() - 0.5
            );
            gameInstance.modules.gore.createBloodSplatter(pos, randomVel, 15);
        }
        lastGoreTime = now;
    }
}
```

### Scenario 4: Landing Tricks (Optional Light Blood)
```javascript
// For hard landings:
function onHardLanding(player) {
    if (gameInstance.modules.gore && landingForce > 0.5) {
        const pos = player.position.clone();
        const vel = new THREE.Vector3(0, 0.1, 0);
        
        // Small blood effect for rough landing
        gameInstance.modules.gore.createBloodSplatter(pos, vel, 10);
    }
}
```

## PERFORMANCE NOTES:

- Maximum 2000 blood particles at once (automatically managed)
- Blood particles last ~16 seconds (1000 frames at 60fps)
- Blood pools last ~50 seconds (3000 frames)
- Body parts last ~10 seconds (600 frames)
- Fades out in the last 20% of lifetime
- All gore uses basic physics (gravity, friction, bouncing)

## CHECKING IF GORE IS ENABLED:

```javascript
if (gameInstance.modules.gore) {
    // Gore is enabled, trigger effects
    gameInstance.modules.gore.createBloodSplatter(...);
} else {
    // Gore is disabled, skip effects
    console.log('Player died (gore disabled)');
}
```

## TOGGLING GORE AT RUNTIME:

```javascript
// Enable gore after initialization:
if (!gameInstance.modules.gore) {
    gameInstance.modules.gore = new ApplesauceGore(gameInstance);
}

// Disable gore at runtime:
if (gameInstance.modules.gore) {
    gameInstance.modules.gore.clear(); // Clean up existing gore
    gameInstance.modules.gore = null;  // Disable system
}
```

## LEVEL-SPECIFIC GORE SETTINGS:

You can configure gore per-level in your level config:

```javascript
window.Level16Config = {
    meta: {
        name: "VOLCANO HELL",
        goreIntensity: "extreme"  // Could be used for custom logic
    },
    
    // In your level loading code:
    onPlayerDeath: (gameInstance, player) => {
        if (gameInstance.modules.gore) {
            // Extra gore for this level
            gameInstance.modules.gore.createMassiveSplatter(
                player.position,
                player.velocity
            );
        }
    }
};
```

```javascript
const mat = new THREE.MeshBasicMaterial({

    //      0xFF00FF for pink cartoon blood

    opacity: 0.8

```

## TROUBLESHOOTING:

**Gore not appearing?**
- Check `gameInstance.modules.gore` is not null
- Make sure `goreEnabled: true` in config
- Check browser console for errors

**Performance issues?**
- Reduce particle counts in createBloodSplatter()
- Lower maxBloodParticles in constructor
- Clear old gore more frequently with .clear()

**Gore falls through terrain?**
- Make sure `engine.getTerrainHeight()` is working
- Check that terrain is properly initialized

## ES MODULE IMPORT:

The gore system is automatically imported by the core engine, but if you need to import it separately:

```javascript
import { ApplesauceGore } from './applesauce-gore-r182.js';

const goreSystem = new ApplesauceGore(gameInstance);
```
