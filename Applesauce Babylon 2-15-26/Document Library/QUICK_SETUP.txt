│  💻 CONSOLE COMMANDS                                             │
└──────────────────────────────────────────────────────────────────┘

// LIST ALL ITEMS
helmetAPI.list()        → Shows all saved helmets
jacketAPI.list()        → Shows all saved jackets

// SWITCH ITEMS
helmetAPI.switchTo(3)   → Switch to helmet slot 3
jacketAPI.switchTo(2)   → Switch to jacket slot 2

// CLEAR SLOTS
helmetAPI.clear(1)      → Delete helmet in slot 1
jacketAPI.clear(5)      → Delete jacket in slot 5

// DEBUG INFO
game.modules.helmet     → Helmet loader instance
game.modules.jacket     → Jacket loader instance
game.player             → Player object (has helmet & jacket as children)

┌──────────────────────────────────────────────────────────────────┐
│  ❌ TROUBLESHOOTING                                              │
└──────────────────────────────────────────────────────────────────┘

PROBLEM: "HelmetLoader is not defined"
FIX: helmet_loader.js not loading. Check file path.

PROBLEM: "JacketLoader is not defined"  
FIX: jacket_loader.js not loading. Check file path.

PROBLEM: No customization visible on player
FIX: Check console for errors. Run in console:
     game.modules.helmet.helmetGroup.visible
     game.modules.jacket.jacketGroup.visible

PROBLEM: Keyboard controls don't work
FIX: Make sure game isn't paused. Check: game.state.paused

PROBLEM: Items don't follow player
FIX: This shouldn't happen - they're child objects.
     Check: game.modules.helmet.helmetGroup.parent === game.player

PROBLEM: HUD shows but no 3D models
FIX: THREE.js not global. Check: typeof window.THREE
