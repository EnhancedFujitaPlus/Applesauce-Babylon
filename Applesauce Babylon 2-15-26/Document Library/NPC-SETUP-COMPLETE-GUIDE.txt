NPC NOT SHOWING - ROOT CAUSE & FIX
===================================

## 🐛 THE ACTUAL PROBLEM:

**Two issues were preventing NPCs from showing:**

### Issue #1: NPCs Not Positioned on Terrain ✅ FIXED
- NPCs were spawning at Y=0 instead of terrain height
- Fixed in `applesauce-dialogue-r182-fixed.js`

### Issue #2: onLevelStart() Never Called ⚠️ CRITICAL
- **The core engine's `loadLevel()` function never calls `onLevelStart()`**
- Your NPCs are defined in config, but never actually spawned!
- This is why you see terrain but no NPCs/enemies

## ✅ THE COMPLETE FIX:

### 1. Update Core Engine
**FILE:** applesauce-core-r182-full-fixed.js

**What changed:**
```javascript
// BEFORE (loadLevel function):
if (levelConfig.objectives && this.modules.objectives) {
    this.modules.objectives.init(levelConfig.objectives);
}
console.log(`✅ Level loaded successfully`);
// ❌ Never calls onLevelStart!

// AFTER:
if (levelConfig.objectives && this.modules.objectives) {
    this.modules.objectives.init(levelConfig.objectives);
}

// Call level's onLevelStart hook
if (levelConfig.onLevelStart && typeof levelConfig.onLevelStart === 'function') {
    console.log('🎬 Calling level onLevelStart...');
    levelConfig.onLevelStart(this);
    console.log('✅ onLevelStart complete');
}

console.log(`✅ Level loaded successfully`);
```

### 2. Update Dialogue Module
**FILE:** applesauce-dialogue-r182-fixed.js
- NPCs now calculate terrain height correctly

### 3. Use Correct HTML Setup
**FILE:** APPLESAUCE-LEVEL-TEMPLATE.html
- Shows exactly how to load ES modules
- Correct script loading order

## 🔧 HTML SETUP (CRITICAL):

### ❌ WRONG WAY (Won't work with r182):
```html
<!-- Old r128 style - DON'T DO THIS -->
<script src="three.min.js"></script>
<script src="game.js"></script>
```

### ✅ RIGHT WAY (ES Modules):
```html
<!-- STEP 1: Load level config (regular script) -->
<script src="./level-test-npcs-config.js"></script>

<!-- STEP 2: Load game engine (ES module) -->
<script type="module">
    import { ApplesauceCore } from './applesauce-core-r182-full-fixed.js';
    
    const game = new ApplesauceCore({
        dialogueEnabled: true,
        enemiesEnabled: true,
        objectivesEnabled: true,
        goreEnabled: true
    });
    
    // Load level
    game.loadLevel(window.LevelTestNPCs);
</script>
```

**KEY POINTS:**
1. Level config = regular `<script src="">` (NO "type='module'")
2. Game engine = `<script type="module">` with imports
3. Load config BEFORE loading engine

## 📝 CONFIG FILES DON'T NEED IMPORTS

Your level config files are just plain JavaScript objects:

```javascript
// level-config.js
// NO IMPORTS NEEDED!

window.LevelXX = {
    meta: { ... },
    terrain: { ... },
    npcs: [ ... ],
    
    onLevelStart: function(game) {
        // This gets called by loadLevel now!
        this.npcs.forEach(npc => {
            game.modules.dialogue.createNPC(npc);
        });
    }
};
```

Load it as regular script:
```html
<script src="./level-config.js"></script>
```
