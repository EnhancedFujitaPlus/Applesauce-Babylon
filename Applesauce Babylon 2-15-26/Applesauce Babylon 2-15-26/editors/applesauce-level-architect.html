Level Building Guide
Building APPLESAUCE Levels
Step-by-step walkthrough for the expanded room graph system.
STEP 01

Create a RoomGraph

Every level starts with a RoomGraph instance. This is a directed graph where nodes are rooms and edges are doorways. The graph handles all world-position calculation via BFS traversal.

const g = new RoomGraph();
STEP 02

Add Rooms

Use g.addRoom(type, label, options). The type determines default dimensions. The options object overrides any default.

const entry = g.addRoom('hallway', 'Entry', { floorLevel: 1, depth: 10, windowWall: 'west', material: 'polished_concrete' });

STEP 03

Set Floor Levels

Each room has floorLevel (default 0). Each floor = 6 world Y units. Negative values go underground. For the LA mansion vibe: enter high, cascade down.

// Enter at floor 1, outdoor at floor 0 const living = g.addRoom('large_room', 'Living', { floorLevel: 1 }); const terrace = g.addRoom('terrace', 'Deck', { floorLevel: 0 }); const gallery = g.addRoom('gallery', 'Upper', { floorLevel: 2 });
STEP 04

Connect Rooms

g.connect(fromId, toId, fromWall, toWall) creates doorways and controls spatial layout. The first room is placed at origin; all others are positioned by BFS.

g.connect(entry.id, living.id, 'south', 'north'); // B placed south of A g.connect(living.id, kitchen.id, 'east', 'west'); // kitchen placed east of living

Compass: north = -Z, south = +Z, east = +X, west = -X

STEP 05

Assign Materials

Set material (walls) and floorMaterial per room. All large surfaces use tri-planar mapping so textures work on walls, floors, and angles without UV stretching.

STEP 06

Add Terrain & Water

Outdoor rooms accept terrain for procedural ground. Pool decks use waterBody for reflective planes.

const pool = g.addRoom('pool_deck', 'Pool', { floorLevel: 0, terrain: 'cliff', waterBody: { shape: 'rectangular', width: 14, depth: 6, offsetX: 0, offsetZ: 4 } });

Terrain types: landscaped (garden), hillside (slope), rooftop (pavers), cliff (drop-off).

STEP 07

Build the Level Config

Pass graph to ModernLevel.createFromGraph() for a config compatible with ApplesauceCore.loadLevel().

const level = ModernLevel.createFromGraph(graph, { rays: 'extreme', skybox: 'golden_hour', levelName: 'My LA Mansion' }); await engine.loadLevel(level);
STEP 08

Tri-Planar Mapping

Large surfaces use tri-planar projection: the shader samples the texture 3 times (XY, XZ, YZ planes) and blends using abs(worldNormal) raised to a sharpness exponent. This prevents stretching where walls meet floors.

The GLSL chunk is stored in material.metadata.triPlanar and injected by the DungeonBuilder at shader compile time via Babylon's onCompiled hook.

DESIGN TIPS

Frutiger-Brutalist Principles

Cascade down: Entry at top floor, step down to outdoor zones. The building unfolds below the player.

Contrast materials: Board-formed concrete walls + terrazzo floors + wood accent rooms. The tension between raw and warm IS the aesthetic.

Long sightlines: Galleries with windowWall and atriums with spansFloors create through-views that reward exploration.

Anchor with water: Pool at the lowest level gives the composition a destination. Every ramp leads toward light and water.
