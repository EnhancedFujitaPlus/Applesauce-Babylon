DIALOGUE ERROR FIX - DOM Elements Missing
==========================================

## 🐛 THE ERROR:

```
Uncaught TypeError: Cannot set properties of null (setting 'textContent')
at ApplesauceDialogue.showLine (applesauce-dialogue-r182.js:66:38)
```

## 🎯 WHAT IT MEANS:

The dialogue system is trying to display text in HTML elements that don't exist! The dialogue module needs these 4 DOM elements:

1. `<div id="speechBubble">` - The dialogue box
2. `<div id="speakerName">` - Shows who's talking
3. `<div id="speechText">` - Shows the dialogue text
4. `<div id="interactPrompt">` - Shows "Press F to talk"

## ✅ THE FIX:

### Option 1: Use The Template HTML
The easiest fix - just use **APPLESAUCE-LEVEL-TEMPLATE.html** which already has everything!

### Option 2: Add Elements To Your HTML
Add this to your HTML's `<body>` section:

```html
<body>
    <!-- Your existing HUD, etc. -->
    
    <!-- ADD THESE: -->
    <div id="speechBubble">
        <div id="speakerName">SPEAKER</div>
        <div id="speechText">Dialogue text goes here...</div>
        <div id="dialoguePrompt">[Press F to continue...]</div>
    </div>
    
    <div id="interactPrompt">Press F to interact</div>
    
    <!-- Your scripts -->
</body>
```

### Option 3: Copy From Working Example
See **DIALOGUE-HTML-SNIPPET.html** for complete copy-paste code including CSS!

## 🎨 CSS STYLING:

The dialogue elements also need CSS to display properly. Add this to your `<style>` tag:

```css
/* Speech bubble on right side */
#speechBubble {
    position: absolute;
    right: 40px;
    top: 50%;
    transform: translateY(-50%);
    background: rgba(255, 255, 255, 0.95);
    border: 4px solid #000;
    border-radius: 20px;
    padding: 25px 30px;
    max-width: 400px;
    display: none;
    z-index: 150;
    box-shadow: 8px 8px 0 rgba(0, 0, 0, 0.5);
}

#speechBubble.active {
    display: block;
}

#speakerName {
    font-size: 24px;
    color: #000;
    font-weight: bold;
    margin-bottom: 10px;
}

#speechText {
    font-size: 18px;
    color: #000;
    line-height: 1.5;
    min-height: 60px;
}

/* Interact prompt at bottom */
#interactPrompt {
    position: absolute;
    bottom: 100px;
    left: 50%;
    transform: translateX(-50%);
    color: #FFD700;
    font-size: 24px;
    text-shadow: 3px 3px 0 #000;
    display: none;
    z-index: 100;
}
```

## 🔍 HOW TO CHECK:

### 1. Open Browser Console (F12)
Look for this warning:
```
⚠️ Dialogue DOM elements not found! Add these to your HTML:
   <div id="speechBubble">
     <div id="speakerName"></div>
     <div id="speechText"></div>
   </div>
   <div id="interactPrompt"></div>
```

If you see this warning, the elements are missing!

### 2. Inspect Your HTML
In browser DevTools, check if these elements exist:
- Right-click page → Inspect
- Look in Elements tab
- Search for "speechBubble"

### 3. Test After Adding
Once you add the elements:
1. Reload the page
2. Walk near an NPC
3. You should see "Press F to talk to [Name]" at bottom
4. Press F
5. Dialogue should appear on right side
