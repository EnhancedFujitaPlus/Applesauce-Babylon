┌──────────────────────────────────────────────────────────────────┐
│  🛹 SKATEBOARD COMPONENTS                                        │
└──────────────────────────────────────────────────────────────────┘

1. DECK
   • Shapes: popsicle, cruiser, oldschool, shaped
   • Materials: maple, bamboo, carbon
   • Wear: pristine → used → beaten → trashed
   • Custom graphics (PNG/JPG)
   • Top/bottom colors
   • Nose/tail distinction

2. TRUCKS
   • Heights: low (0.12), mid (0.15), high (0.18)
   • Materials: aluminum, titanium, hollow
   • Custom truck color
   • Colored bushings
   • Kingpin visible
   • Realistic geometry

3. WHEELS
   • Size: 0.12-0.18 diameter
   • Hardness: 78-101 (soft→hard)
   • Color indicators (blue/green/red)
   • Wheel cores (inner color)
   • Wear/coning (0-100)
   • Animated rotation

4. GRIP TAPE
   • Patterns: solid, perforated, clear, colored
   • Custom patterns (images)
   • Wear simulation
   • Rough texture

5. BEARINGS
   • Visible on wheels
   • ABEC ratings (1/3/5/7/9, Ceramic)
   • Colored rings
   • Shields optional
   • Animated spinning

FROM CORE ENGINE (createPlayer method):

Default Deck:
  BoxGeometry(0.8 width, 0.1 thick, 2.5 length)
  Position: y = 0.3

Default Wheels:
  CylinderGeometry(0.15 radius, 0.15 radius, 0.1 width)
  Positions:
    Front-left:  [-0.3, 0.15, -0.8]
    Front-right: [ 0.3, 0.15, -0.8]
    Back-left:   [-0.3, 0.15,  0.8]
    Back-right:  [ 0.3, 0.15,  0.8]

Custom Board:
  Replaces default automatically
  Matches dimensions or scales proportionally

┌──────────────────────────────────────────────────────────────────┐
│  💡 PRO TIPS                                                     │
└──────────────────────────────────────────────────────────────────┘

1. Load Order Matters!
   Skateboard → Jacket → Helmet
   (Bottom to top layers)

2. Wheel Animation
   Don't forget: skateboard.update(speed) in game loop!

3. Default Board Removal
   Automatic! Loader finds and removes BoxGeometry(2.5) deck

4. Realistic Hardness
   Street: 99-101a (red indicator)
   Park: 95-98a (green indicator)
   Cruiser: 78-87a (blue indicator)

5. Wear Progression
   pristine (0%) → used (30%) → beaten (60%) → trashed (90%)

6. Custom Graphics
   Use transparent PNGs for best results
   Keep under 1MB for fast loading

7. Testing in Console
   game.modules.skateboard.currentSkateboardData
   game.modules.skateboard.wheels // Array of wheel meshes
