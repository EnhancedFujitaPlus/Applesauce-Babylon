## 🎮 QUICK START:

### Step 1: Replace Your Core File
Use **applesauce-core-r182-full.js** instead of your old core

### Step 2: Add All Module Files
Make sure you have all five module files:
- applesauce-gore-r182.js
- applesauce-dialogue-r182.js
- applesauce-enemies-r182.js
- applesauce-objectives-r182.js

### Step 3: Initialize Game
```javascript
const game = new ApplesauceCore({
    goreEnabled: true,           // Enable gore (default: true)
    dialogueEnabled: true,       // Enable dialogue (default: true)
    enemiesEnabled: true,        // Enable enemies (default: true)
    objectivesEnabled: true      // Enable objectives (default: true)
});
```

All modules are enabled by default! You can disable any module by setting its config to `false`.

## 💬 DIALOGUE MODULE

**Create NPCs:**
```javascript
const npc = game.modules.dialogue.createNPC({
    name: "Skate Guru",
    position: { x: 10, y: 0, z: 20 },
    color: 0x00FF00,
    interactRadius: 5,
    dialogue: [
        { speaker: "Skate Guru", text: "Welcome to the park!" },
        { speaker: "Skate Guru", text: "Press Q for kickflips!" }
    ]
});
```

**How it works:**
- Player walks near NPC (within interactRadius)
- Prompt appears: "Press F to talk to [Name]"
- Press F to start dialogue
- Press F again to advance through lines
- Letter-by-letter typing animation
- Press F to skip typing animation

**Required HTML elements:**
```html
<div id="speechBubble" class="speech-bubble">
    <div id="speakerName"></div>
    <div id="speechText"></div>
</div>
<div id="interactPrompt"></div>
```

## 👀 ENEMIES MODULE

**Spawn Enemies:**
```javascript
// Single enemy
const enemy = game.modules.enemies.spawnEnemy({
    position: { x: 0, z: 50 },
    behavior: 'wander',  // 'wander', 'static', 'flee'
    speed: 0.02,
    color: 0xFF6666
});

// Line formation
game.modules.enemies.spawnLine(0, 50, 5, 3);  // x, z, count, spacing

// Cluster formation
game.modules.enemies.spawnCluster(0, 50, 8, 5);  // x, z, count, radius

// Boss enemy
const boss = game.modules.enemies.spawnBoss({
    position: { x: 0, z: 100 },
    health: 10,
    speed: 0.03
});
```

**Collision System:**
- Player speed > 0.2 = ROADKILL (enemy dies)
- Player speed < 0.2 = BUMP (player slowed)
- Roadkills trigger gore effects automatically
- Adds 500 * combo to score
- Tracks kills for objectives

**Enemy Behaviors:**
- **wander**: Random walking around
- **static**: Doesn't move
- **flee**: Runs away from player (within 20 units)

**Boss:**
- 10 health (takes multiple hits to kill)
- Always chases player
- Melee attack when close
- Flash red when damaged

## 🎯 OBJECTIVES MODULE

**Auto-load from Level Config:**
```javascript
// In your level config:
window.Level01Config = {
    objectives: {
        survive: { 
            duration: 180,
            description: "Survive 3 minutes"
        },
        score: { 
            target: 10000,
            description: "Reach 10,000 points"
        },
        kills: {
            count: 5,
            description: "Roadkill 5 people"
        }
    }
};

// Objectives auto-load when level loads!
```

**Manual Creation:**
```javascript
// Roadkill objective
game.modules.objectives.addKillObjective(10, "Roadkill 10 people");

// Score objective
game.modules.objectives.addScoreObjective(50000, "Get 50k points");

// Trick objective
game.modules.objectives.addTrickObjective('kickflip', 5, "Land 5 kickflips");

// Boss objective
game.modules.objectives.addBossObjective("Defeat the boss");

// Custom objective
game.modules.objectives.add({
    id: 'custom',
    description: "Do something cool",
    type: 'custom',
    target: 1,
    checker: (engine) => {
        // Return current progress
        return engine.customCounter || 0;
    },
    onComplete: (engine) => {
        console.log('Custom objective complete!');
    }
});
```

**Required HTML element:**
```html
<div id="objectives"></div>
```

## 🔗 HOW MODULES WORK TOGETHER:

### Example: Roadkill with Gore
```javascript

// 1. Enemies module detects collision
// 2. Enemies module calls gore.createMassiveSplatter()
// 3. Enemies module increments kill count
```

## 🧹 CLEANUP:

All modules have `.clear()` methods that are automatically called when switching levels:

```javascript
// Manual cleanup (usually not needed)
game.modules.gore.clear();        // Remove all blood/gibs
game.modules.dialogue.clear();    // Remove all NPCs
game.modules.enemies.clear();     // Remove all enemies
game.modules.objectives.clear();  // Clear all objectives
```

The core engine handles this automatically in `game.clearLevel()`.

## 🐛 TROUBLESHOOTING:

**Modules not loading?**
- Check all module files are in same folder as core
- Verify imports in applesauce-core-r182-full.js
- Open browser console (F12) for errors

**Objectives not updating?**
- Make sure objectives module is enabled
- Check that `<div id="objectives"></div>` exists in HTML
- Verify checker functions return correct values

**NPCs not appearing?**
- Check dialogue module is enabled
- Verify NPC position is on terrain
- Look for console errors

**Enemies not dying?**
- Make sure player speed > 0.2 for roadkills
- Check gore module is enabled for visual feedback
- Verify collision detection is working

**Gore not showing?**
- Ensure goreEnabled: true in config
- Check that gore effects are being called
- Run gore-test-demo.html to verify setup
