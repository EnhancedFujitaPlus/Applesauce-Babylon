NPC SPAWN FIX - QUICK GUIDE
===========================

## 🐛 THE PROBLEM:

NPCs weren't appearing in your levels because they weren't calculating their Y position based on terrain height. They were spawning at Y=0, which with the new terrain system meant they could be underground or at the wrong height.

## ✅ THE FIX:

Updated `applesauce-dialogue-r182.js` to calculate NPC positions correctly:

### What Changed:

**BEFORE (Broken):**
```javascript
this.mesh.position.set(this.position.x, this.position.y, this.position.z);
// Used Y from config (always 0)
// NPCs spawned underground or at wrong height!
```

**AFTER (Fixed):**
```javascript
this.updatePosition();  // Call this method

updatePosition() {
    const groundY = this.engine.getTerrainHeight(this.position.x, this.position.z);
    this.mesh.position.set(this.position.x, groundY, this.position.z);
}
// NPCs now spawn at correct terrain height!
```

### Common Issues:

**Issue: "getTerrainHeight is not a function"**
- Core engine doesn't have terrain module
- Make sure using updated core with terrain support

**Issue: "createNPC is not a function"**
- Dialogue module not properly loaded
- Check import statement in HTML

**Issue: NPCs spawn but are underground**
- Terrain hasn't generated yet when NPCs spawn
- Make sure `onLevelStart()` is called AFTER terrain generation

**Issue: NPCs spawn at (0, 0, 0)**
- Position not being read from config
- Check config has `position: { x, y, z }`

## 🚀 APPLYING TO YOUR LEVELS:

Once you confirm test level works, update your real level configs:

### Your Level Config:
```javascript
npcs: [
    {
        name: "Skate Coach",
        position: { x: -5, y: 0, z: 30 },  // Y=0 is fine!
        color: 0x00FF00,
        interactRadius: 5,
        dialogue: [
            { speaker: "Skate Coach", text: "Welcome!" }
        ]
    }
],

onLevelStart: function(game) {
    // Spawn NPCs
    if (game.modules.dialogue && this.npcs) {
        this.npcs.forEach(npcConfig => {
            game.modules.dialogue.createNPC(npcConfig);
        });
    }
}
```
