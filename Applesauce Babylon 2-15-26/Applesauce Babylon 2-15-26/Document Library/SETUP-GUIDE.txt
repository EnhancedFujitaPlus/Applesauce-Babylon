APPLESAUCE MODULAR MENU SYSTEM - SETUP GUIDE
=============================================

This guide will help you get your modular menu system and level loader working!

## THE PROBLEM YOU HAD:
You were getting "THREE is not defined" because the core engine tried to use 
THREE.js before it was fully loaded.

## THE SOLUTION:
The fixed HTML file now waits for THREE.js to load before initializing the game.

## FILE STRUCTURE:
Your folder should look like this:

your-game-folder/
├── applesauce-main-menu-fixed.html    ← The main file (open this!)
├── applesauce-core-r182.js            ← Your game engine
├── level-01-config.js                 ← Level 1 configuration
└── three.min.js (optional)            ← If using local Three.js

## SETUP INSTRUCTIONS:

### OPTION 1: Using CDN (Easiest - Recommended)
1. Just use the files as-is
2. Open `applesauce-main-menu-fixed.html` in your browser
3. It will load Three.js from the internet automatically

### OPTION 2: Using Downloaded Three.js
If you want to use your downloaded three.js-master folder:

1. Find this file in your three.js-master folder:
   `three.js-master/build/three.min.js`

2. Copy it to your game folder

3. In applesauce-main-menu-fixed.html, change line 10 from:
   <script src="https://cdnjs.cloudflare.com/ajax/libs/three.js/r182/three.min.js"></script>
   
   To:
   <script src="three.min.js"></script>

## TESTING:
1. Open applesauce-main-menu-fixed.html in a web browser
2. You should see the APPLESAUCE main menu
3. Click "CAREER MODE"
4. Click on "LEVEL 1 - TUTORIAL HILL"
5. The game should load!

## TROUBLESHOOTING:

### "Failed to load core engine"
- Make sure applesauce-core-r182.js is in the same folder as the HTML file
- Check that the filename is spelled exactly right

### "Failed to load level"
- Make sure level-01-config.js is in the same folder
- Open browser console (F12) to see detailed error messages

### "Config not found: Level01Config"
- Make sure your level config file has: window.Level01Config = {...}
- Check the console.log at the bottom of the config file

### Game loads but screen is black
- Open browser console (F12) to check for errors
- Make sure the config has proper terrain and player settings

## ADDING MORE LEVELS:

1. Create a new config file (e.g., level-02-config.js):
   ```javascript
   window.Level02Config = {
       meta: {
           name: "YOUR LEVEL NAME",
           number: 2,
           ...
       },
       ...
   };
   console.log('✅ Level 02 Config Loaded');
   ```

2. Add it to the LEVEL_REGISTRY in the HTML file:
   ```javascript
   const LEVEL_REGISTRY = [
       {
           id: 1,
           name: "TUTORIAL HILL",
           description: "Learn the basics",
           difficulty: "EASY",
           configPath: "level-01-config.js"
       },
       {
           id: 2,
           name: "YOUR LEVEL NAME",
           description: "Your description",
           difficulty: "MEDIUM",
           configPath: "level-02-config.js"
       }
   ];
   ```
