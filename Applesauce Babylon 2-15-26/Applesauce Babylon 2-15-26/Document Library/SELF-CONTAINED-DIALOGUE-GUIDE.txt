SELF-CONTAINED DIALOGUE SYSTEM - UNIVERSAL SETUP
=================================================

## 🎯 THE SOLUTION:

The dialogue module now **creates its own UI automatically**! 

### What This Means:
- ✅ NO need to add HTML elements to every level
- ✅ NO need to copy CSS to every file
- ✅ ONE dialogue module works for ALL levels
- ✅ Speech bubble appears automatically when module loads

## 📦 HOW IT WORKS:

### When the dialogue module loads:
1. Checks if UI elements exist
2. If not, creates them automatically
3. Injects CSS styles into the page
4. Sets up event listeners

### Result:
**Any HTML file that loads the dialogue module gets the full UI automatically!**

## 🎮 HOW TO USE:

### For Each New Level:

**Option 1: Change Script Tag (Easiest)**
```html
<!-- In UNIVERSAL-LEVEL-TEMPLATE.html, just change this line: -->
<script src="./level-01-tutorial-config.js"></script>
<!-- To whatever level you want to load -->
```

**Option 2: Copy HTML Template**
```bash
# Make a copy for each level
cp UNIVERSAL-LEVEL-TEMPLATE.html Level-01.html
cp UNIVERSAL-LEVEL-TEMPLATE.html Level-05.html
cp UNIVERSAL-LEVEL-TEMPLATE.html Level-10.html

# Edit each one to load its level config
```

**Option 3: Dynamic Level Selector**
```html
<!-- Add this to your HTML: -->
<select id="levelSelect">
    <option value="LevelTestNPCs">Test Level</option>
    <option value="Level01Config">Level 1: Tutorial</option>
    <option value="Level05Config">Level 5: Combat</option>
</select>

<script type="module">
    import { ApplesauceCore } from './applesauce-core-r182-full-fixed.js';
    
    const game = new ApplesauceCore({ dialogueEnabled: true });
    
    document.getElementById('levelSelect').addEventListener('change', (e) => {
        const levelConfig = window[e.target.value];
        if (levelConfig) {
            game.loadLevel(levelConfig);
        }
    });
</script>
```

## 📝 YOUR LEVEL .JS FILES:

### Level configs stay the same!
```javascript
// level-XX-config.js
// No changes needed!

window.LevelXXConfig = {
    meta: {
        name: "My Level",
        number: XX
    },
    
    terrain: { ... },
    
    npcs: [
        {
            name: "Guide NPC",
            position: { x: 0, y: 0, z: 20 },
            color: 0x00FF00,
            dialogue: [
                { speaker: "Guide NPC", text: "Hello!" }
            ]
        }
    ],
    
    onLevelStart: function(game) {
        // Spawn NPCs
        if (game.modules.dialogue && this.npcs) {
            this.npcs.forEach(npc => {
                game.modules.dialogue.createNPC(npc);
            });
        }
    }
};
```

### The dialogue UI appears automatically! No extra code needed.

## ✨ WHAT HAPPENS AUTOMATICALLY:

### 1. When Game Loads:
```
💬 Dialogue module loaded (self-contained UI)
💬 Creating dialogue UI elements...
✅ Dialogue UI elements created
```

### 2. UI Elements Created:
- `<div id="speechBubble">` - Speech bubble (right side)
- `<div id="speakerName">` - Speaker's name
- `<div id="speechText">` - Dialogue text
- `<div id="interactPrompt">` - "Press F" prompt (bottom)

### 3. CSS Styles Injected:
- Speech bubble styling
- Pop-in animation
- Interact prompt bounce animation
- All colors and positioning

### 4. Event Listeners Set:
- F key to interact
- F key to advance dialogue
- Distance checking for nearby NPCs

## 🎨 CUSTOMIZING THE UI:

### If you want to customize the appearance:

**Option 1: Override CSS in your HTML**
```html
<style>
/* Override default dialogue styles */
#speechBubble {
    background: rgba(0, 0, 0, 0.9) !important;  /* Dark background */
    border: 4px solid #FFD700 !important;      /* Gold border */
}

#speakerName {
    color: #FFD700 !important;  /* Gold text */
}
</style>
```

**Option 2: Modify the module**
Edit `applesauce-dialogue-r182-self-contained.js` in the `_createStyles()` function.

## 🔧 TROUBLESHOOTING:

### "Speech bubble doesn't appear"
```
1. Check console for:
   💬 Creating dialogue UI elements...
   ✅ Dialogue UI elements created

2. Check if dialogue module loaded:
   💬 Dialogue module loaded (self-contained UI)

3. Check if dialogueEnabled:
   new ApplesauceCore({ dialogueEnabled: true })
```

### "UI appears twice"
```
This means:
1. Dialogue module creates UI ✅
2. Your HTML also has <div id="speechBubble"> ❌

Solution: Remove manual UI from HTML
The module will use existing elements if they're there.
```

### "Styling looks wrong"
```
1. Check for conflicting CSS in your HTML
2. Use !important to override:
   #speechBubble { background: red !important; }

3. Or edit _createStyles() in the module
```
