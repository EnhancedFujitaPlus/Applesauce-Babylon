NEW TERRAIN SYSTEM GUIDE
========================

The terrain system has been completely rebuilt! No more weird cylinder blobs - now you have proper chunk-based terrain generation with hills, flats, mountains, and valleys.

## 🔧 WHAT WAS FIXED:

**OLD SYSTEM PROBLEMS:**
❌ Hill was a cylinder (weird blob physics)
❌ getTerrainHeight() only worked in certain Z ranges
❌ NPCs and enemies spawned underground or at wrong height
❌ No modularity - couldn't mix terrain types

**NEW SYSTEM BENEFITS:**
✅ Proper geometry for all terrain types
✅ Reliable height lookup anywhere on the map
✅ NPCs and enemies spawn at correct height automatically
✅ Chunk-based: mix hills, flats, mountains, valleys
✅ Easy to extend with new terrain types

## 🏔️ TERRAIN TYPES:

### 1. FLAT
Flat ground at a specified height.
```javascript
{
    type: 'flat',
    length: 200,
    height: 0,
    width: 200
}
```

### 2. HILL (Downhill slope)
Smooth slope from high to low.
```javascript
{
    type: 'hill',
    length: 200,
    startHeight: 60,
    endHeight: 0,
    width: 200
}
```

### 3. MOUNTAIN
Peak in the center, slopes down to edges.
```javascript
{
    type: 'mountain',
    length: 150,
    peakHeight: 80,
    width: 200
}
```

### 4. VALLEY
Low center, high edges (opposite of mountain).
```javascript
{
    type: 'valley',
    length: 150,
    depth: -20,
    width: 200
}
```

## 📝 USING IN LEVEL CONFIGS:

### Simple Mode (Backwards Compatible)
Your existing configs still work!

```javascript
terrain: {
    size: 500,
    hill: true,      // Classic downhill
    hillHeight: 60,
    hillLength: 200
}
// This automatically creates:
// - 200 units of downhill (60m → 0m)
// - 300 units of flat ground
```

### Advanced Mode (Custom Segments)
Build custom terrain with multiple chunks:

```javascript
terrain: {
    segments: [
        // Start with flat section
        {
            type: 'flat',
            length: 100,
            height: 50
        },
        // Downhill
        {
            type: 'hill',
            length: 200,
            startHeight: 50,
            endHeight: 0
        },
        // Valley
        {
            type: 'valley',
            length: 150,
            depth: -15
        },
        // Mountain climb
        {
            type: 'mountain',
            length: 200,
            peakHeight: 70
        },
        // Final flat section
        {
            type: 'flat',
            length: 150,
            height: 0
        }
    ]
}
```

### Example 3: Procedural Terrain
```javascript
window.Level10Config = {
    meta: {
        name: "RANDOM TERRAIN",
        number: 10
    },
    
    terrain: {
        segments: generateRandomTerrain()
    },
    
    playerStart: { x: 0, z: 10 }
};

function generateRandomTerrain() {
    const segments = [];
    const types = ['flat', 'hill', 'mountain', 'valley'];
    const count = 8;
    
    for (let i = 0; i < count; i++) {
        const type = types[Math.floor(Math.random() * types.length)];
        
        let segment = { type, length: 100 + Math.random() * 100 };
        
        switch(type) {
            case 'flat':
                segment.height = Math.random() * 40 - 20;
                break;
            case 'hill':
                segment.startHeight = Math.random() * 60;
                segment.endHeight = Math.random() * 40;
                break;
            case 'mountain':
                segment.peakHeight = 50 + Math.random() * 50;
                break;
            case 'valley':
                segment.depth = -(10 + Math.random() * 20);
                break;
        }
        
        segments.push(segment);
    }
    
    return segments;
}
```

## 🎯 HOW IT WORKS INTERNALLY:

### Height Lookup System:
```javascript
// NPCs and enemies call this automatically:
const height = game.getTerrainHeight(x, z);

// Which calls:
game.modules.terrain.getHeight(x, z);

// The terrain module:
// 1. Checks heightMap for exact match
// 2. Finds correct chunk based on Z position
// 3. Interpolates from nearest height data
// 4. Returns accurate height for ANY position
```

### NPC/Enemy Spawning:
```javascript
// In applesauce-enemies-r182.js:
updatePosition() {
    const groundY = this.engine.getTerrainHeight(this.position.x, this.position.z);
    this.mesh.position.set(this.position.x, groundY, this.position.z);
}
// This runs every frame, so enemies always stick to terrain!
```

## 🛠️ TERRAIN PARAMETERS:

### Flat Terrain:
- **length**: How long the flat section (default: 100)
- **width**: How wide the terrain (default: 200)
- **height**: Y position of the flat plane (default: 0)

### Hill Terrain:
- **length**: How long the slope (default: 100)
- **width**: How wide (default: 200)
- **startHeight**: Y at the beginning (default: 60)
- **endHeight**: Y at the end (default: 0)

### Mountain Terrain:
- **length**: Size of mountain (default: 100)
- **width**: Width (default: 200)
- **peakHeight**: How tall the peak (default: 80)

### Valley Terrain:
- **length**: Size of valley (default: 100)
- **width**: Width (default: 200)
- **depth**: How low the center goes (negative number, default: -20)

## 🐛 TROUBLESHOOTING:

**NPCs still not appearing?**
- Check console for "💬 Dialogue module loaded"
- Check console for "NPC spawned" messages
- Verify onLevelStart() is being called
- Check if dialogue module is enabled

**Enemies still not appearing?**
- Check console for "👀 Enemies module loaded"
- Check console for "Enemy spawned" messages  
- Verify onLevelStart() is being called
- Check if enemies module is enabled

**Terrain looks weird?**
- Check segment order (startZ should increase)
- Verify heights make sense (not too extreme)
- Check that segments don't overlap
- Look for console errors

**Performance issues?**
- Reduce segment detail (lower resolution in heightData generation)
- Use fewer segments
- Reduce width of terrain chunks
- Optimize other systems (fewer enemies, simpler obstacles)
