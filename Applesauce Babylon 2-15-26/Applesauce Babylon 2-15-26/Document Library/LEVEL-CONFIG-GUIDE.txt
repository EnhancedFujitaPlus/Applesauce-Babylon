LEVEL CONFIG GUIDE - Using All Systems
======================================

This guide shows you how to set up levels with all the modular systems:
- 🩸 Gore
- 💬 Dialogue & NPCs  
- 👀 Enemies & AI
- 🎯 Objectives

## 📋 LEVEL CONFIG STRUCTURE:

```javascript
window.LevelXXConfig = {
    meta: { ... },           // Level info
    scene: { ... },          // Visuals
    playerStart: { ... },    // Starting position
    terrain: { ... },        // Ground setup
    obstacles: { ... },      // Rails, ramps, etc.
    
    // NEW: Module configurations
    objectives: { ... },     // Auto-loaded by objectives module
    npcs: [ ... ],          // Spawned in onLevelStart
    enemies: { ... },       // Spawned in onLevelStart
    boss: { ... },          // Optional boss config
    
    onLevelStart: function(game) {
        // Custom initialization code
    },
    
    scoring: { ... }
};
```

## 🎯 OBJECTIVES CONFIGURATION

Objectives are **automatically loaded** from the config!

### Available Objective Types:

```javascript
objectives: {
    // Survive for X seconds
    survive: { 
        duration: 180,  // seconds
        description: "Survive 3 minutes"
    },
    
    // Reach a score
    score: { 
        target: 50000,
        description: "Reach 50,000 points"
    },
    
    // Land tricks
    tricks: {
        kickflips: 10,  // Number of kickflips to land
        description: "Land 10 kickflips"
    },
    
    // Grind rails
    grinds: {
        count: 5,
        description: "Grind 5 rails"
    },
    
    // Roadkill enemies
    kills: {
        count: 20,
        description: "Roadkill 20 enemies"
    },
    
    // Defeat boss
    boss: {
        description: "Defeat the boss"
    }
}
```

**How it works:**
- Put objectives in your level config
- The objectives module reads them automatically when level loads
- Progress tracked automatically
- Displays in HUD automatically

## 💬 NPC CONFIGURATION

NPCs must be **spawned manually** in `onLevelStart()`.

### NPC Setup:

```javascript
npcs: [
    {
        name: "Skate Coach",
        position: { x: 0, y: 0, z: 10 },
        color: 0x00FF00,           // Green
        interactRadius: 5,         // Player can interact within 5 units
        dialogue: [
            { speaker: "Skate Coach", text: "Welcome!" },
            { speaker: "Skate Coach", text: "Press Q for tricks!" }
        ]
    }
],

onLevelStart: function(game) {
    // Spawn all NPCs
    if (game.modules.dialogue && this.npcs) {
        this.npcs.forEach(npcConfig => {
            game.modules.dialogue.createNPC(npcConfig);
        });
    }
}
```

**How it works:**
- Player walks near NPC → "Press F to talk" appears
- Press F → Dialogue starts with letter-by-letter typing
- Press F again → Advance to next line
- Dialogue ends → NPC still there, can talk again

## 👀 ENEMY CONFIGURATION

Enemies must be **spawned manually** in `onLevelStart()`.

### Enemy Patterns:

#### 1. Line Formation
```javascript
enemies: {
    wander: [
        { position: { x: 0, z: 50 }, count: 5, spacing: 8 }
    ]
},

onLevelStart: function(game) {
    if (game.modules.enemies) {
        this.enemies.wander.forEach(group => {
            game.modules.enemies.spawnLine(
                group.position.x,
                group.position.z,
                group.count,
                group.spacing
            );
        });
    }
}
```

#### 2. Cluster Formation
```javascript
enemies: {
    clusters: [
        { position: { x: 0, z: 100 }, count: 8, radius: 10 }
    ]
},

onLevelStart: function(game) {
    if (game.modules.enemies) {
        this.enemies.clusters.forEach(cluster => {
            game.modules.enemies.spawnCluster(
                cluster.position.x,
                cluster.position.z,
                cluster.count,
                cluster.radius
            );
        });
    }
}
```

#### 3. Different Behaviors
```javascript
// Wandering enemies (walk around randomly)
game.modules.enemies.spawnEnemy({
    position: { x: 10, z: 50 },
    behavior: 'wander',
    speed: 0.02
});

// Fleeing enemies (run from player)
game.modules.enemies.spawnEnemy({
    position: { x: 10, z: 50 },
    behavior: 'flee',
    speed: 0.03,
    color: 0xFFFF00  // Yellow
});

// Static enemies (don't move)
game.modules.enemies.spawnEnemy({
    position: { x: 10, z: 50 },
    behavior: 'static',
    color: 0xFF0000  // Red
});
```

#### 4. Boss Enemy
```javascript
boss: {
    position: { x: 0, z: 200 },
    health: 20,
    speed: 0.04,
    color: 0xFF0000
},

onLevelStart: function(game) {
    if (game.modules.enemies && this.boss) {
        const boss = game.modules.enemies.spawnBoss({
            position: this.boss.position,
            health: this.boss.health,
            speed: this.boss.speed,
            color: this.boss.color
        });
    }
}
```

## 🩸 GORE SYSTEM

Gore is **automatic** when enemies die! No config needed.

**How it works:**
- Player hits enemy at high speed → Enemy dies
- Enemies module triggers gore automatically:
  - Speed > 0.5 = Massive splatter
  - Speed < 0.5 = Regular blood + gibs
- Blood physics, body parts tumbling, all automatic!

**Disable gore for a level:**
```javascript
onLevelStart: function(game) {
    // Disable gore for family-friendly levels
    if (game.modules.gore) {
        game.modules.gore.clear();
        game.modules.gore = null;
    }
}
```

## 🔧 ADVANCED TECHNIQUES:

### Custom Events on Boss Death
```javascript
onLevelStart: function(game) {
    if (game.modules.enemies) {
        const originalUpdate = game.modules.enemies.update.bind(game.modules.enemies);
        
        game.modules.enemies.update = function(engine) {
            originalUpdate(engine);
            
            // Check if boss is dead
            if (this.boss && this.boss.isDead && !this.bossDefeatedTriggered) {
                this.bossDefeatedTriggered = true;
                
                // VICTORY!
                console.log('🎉 BOSS DEFEATED!');
                
                // Huge gore explosion
                for (let i = 0; i < 10; i++) {
                    setTimeout(() => {
                        engine.modules.gore.createMassiveSplatter(...);
                    }, i * 200);
                }
                
                // Bonus points
                engine.state.score += 10000;
                
                // Show victory screen
                setTimeout(() => {
                    alert('VICTORY!');
                }, 2000);
            }
        };
    }
}
```

### Progressive Enemy Spawning
```javascript
onLevelStart: function(game) {
    // Spawn first wave immediately
    game.modules.enemies.spawnLine(0, 50, 5, 8);
    
    // Spawn second wave after 30 seconds
    setTimeout(() => {
        game.modules.enemies.spawnLine(20, 100, 8, 6);
        console.log('📢 SECOND WAVE!');
    }, 30000);
    
    // Spawn third wave after 60 seconds
    setTimeout(() => {
        game.modules.enemies.spawnCluster(0, 150, 10, 15);
        console.log('📢 FINAL WAVE!');
    }, 60000);
}
```

### Milestone Events
```javascript
onLevelStart: function(game) {
    game.milestones = {
        halfwayReached: false,
        tenKillsReached: false
    };
    
    const originalEnemiesUpdate = game.modules.enemies.update.bind(game.modules.enemies);
    
    game.modules.enemies.update = function(engine) {
        originalEnemiesUpdate(engine);
        
        // Halfway milestone
        if (!engine.milestones.halfwayReached && this.kills >= 10) {
            engine.milestones.halfwayReached = true;
            console.log('🎯 Halfway there!');
        }
        
        // 10 kills milestone
        if (!engine.milestones.tenKillsReached && this.kills >= 10) {
            engine.milestones.tenKillsReached = true;
            console.log('🎯 10 KILLS! Keep going!');
        }
    };
}
```

## ✅ CHECKLIST FOR NEW LEVELS:

1. **Basic Setup**
   - [ ] Meta info (name, difficulty, description)
   - [ ] Scene colors (background, fog)
   - [ ] Terrain config (size, hill)
   - [ ] Player start position
   - [ ] Obstacles (rails, ramps, etc.)

2. **Objectives**
   - [ ] Add objectives to config
   - [ ] Make sure objectives module is enabled
   - [ ] Objectives will auto-load!

3. **NPCs (Optional)**
   - [ ] Add npcs array to config
   - [ ] Write dialogue for each NPC
   - [ ] Spawn NPCs in onLevelStart()

4. **Enemies (Optional)**
   - [ ] Add enemies config
   - [ ] Choose behaviors (wander, flee, static)
   - [ ] Spawn enemies in onLevelStart()
   - [ ] Add boss if desired

5. **Gore**
   - [ ] Gore auto-triggers on enemy death
   - [ ] Disable if making family-friendly level

6. **Test**
   - [ ] Load level in game
   - [ ] Check console for spawn messages
   - [ ] Verify objectives appear in HUD
   - [ ] Test NPC interactions (Press F)
   - [ ] Test enemy collisions
   - [ ] Check gore effects

## 🚀 TIPS:

- Start simple! Copy level-01-tutorial-config.js as a template
- Test each system individually before combining
- Use console.log() liberally in onLevelStart() for debugging
- Check browser console (F12) for errors
- Enemies need space - don't spawn them too close together
- NPCs should be placed where player will see them
- Balance is key - too many enemies = overwhelming
