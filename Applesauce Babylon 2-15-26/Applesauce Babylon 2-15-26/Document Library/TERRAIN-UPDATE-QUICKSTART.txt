## 🎮 TEST YOUR LEVELS:

### Quick Test Checklist:
1. Load your existing level
2. Check console for these messages:
   ```
   🏔️ Terrain module loaded
   🏔️ Creating terrain from config...
   🏔️ Generating terrain...
   ✅ Generated X terrain chunks
   ```
3. Look for NPCs - they should be visible and on the ground
4. Look for enemies - they should be visible and moving
5. Player should move smoothly on terrain

### If NPCs Don't Appear:
1. Open console (F12)
2. Look for "💬 Dialogue module loaded"
3. Look for "NPC spawned" or similar messages
4. Check your onLevelStart() function:
   ```javascript
   onLevelStart: function(game) {
       if (game.modules.dialogue && this.npcs) {
           this.npcs.forEach(npcConfig => {
               game.modules.dialogue.createNPC(npcConfig);
           });
       }
   }
   ```

### If Enemies Don't Appear:
1. Open console (F12)
2. Look for "👀 Enemies module loaded"
3. Check your onLevelStart() function
4. Make sure you're spawning enemies:
   ```javascript
   onLevelStart: function(game) {
       if (game.modules.enemies) {
           game.modules.enemies.spawnLine(0, 50, 5, 8);
       }
   }
   ```

## 🐛 COMMON ISSUES:

### Issue: "terrain module not found"
**Solution:** Make sure applesauce-terrain-r182.js is in same folder as HTML

### Issue: "THREE is not defined" in terrain module
**Solution:** Using live server? ES modules require a server.

### Issue: NPCs/Enemies still underground
**Solution:** 
1. Check console for terrain generation messages
2. Verify onLevelStart() is spawning them correctly
3. Try the showcase level to verify system works

### Issue: Terrain looks weird/glitchy
**Solution:**
1. Check segment heights aren't too extreme (±100 is usually max)
2. Make sure segments are in order (Z values increasing)
3. Verify no overlapping segments

### Issue: Performance problems
**Solution:**
1. Reduce number of terrain segments
2. Use simpler terrain (fewer mountains/valleys)
3. Reduce terrain width
4. Check other systems (enemies, obstacles)
