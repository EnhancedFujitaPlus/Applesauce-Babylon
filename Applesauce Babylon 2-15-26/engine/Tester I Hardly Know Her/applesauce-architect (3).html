Level Building Guide
Building APPLESAUCE Levels
Step-by-step guide for creating levels, previewing in 3D, and exporting to Babylon.js + Havok scenes.
STEP 01

Create a RoomGraph

Every level is a directed graph: nodes = rooms, edges = doorways. The system calculates all world positions via BFS from the first room.

const g = new RoomGraph();
STEP 02

Add Rooms

g.addRoom(type, label, opts) — type sets defaults, opts override anything. Returns a node with .id for connecting.

STEP 03

Connect & Layout

g.connect(fromId, toId, fromWall, toWall) — compass walls control 2D placement. north=-Z, south=+Z, east=+X, west=-X. Floor levels set Y position (6 units per floor).

STEP 04

Materials & Terrain

Set material (walls) and floorMaterial per room. Outdoor rooms use terrain for ground generation. Pool decks auto-create water planes from waterBody.

STEP 05

Preview & Export

Use the 3D Preview tab to inspect your scene with orbit controls. When ready, hit Export Babylon Scene to download a standalone HTML file with full Babylon.js + Havok physics, FPS camera, procedural PBR materials, and all geometry. Open it in any browser — it's a complete, runnable game template.

TIPS

Design Principles

Cascade down: Entry high, outdoor zones low. Contrast materials: Board-formed walls + terrazzo floors + wood accents. Long sightlines: Galleries and atriums with through-views. Anchor with water: Pool at the bottom as destination.
